# 📝 Analizador de Texto IA

Una aplicación web integral que utiliza inteligencia artificial para analizar y mejorar textos académicos en español. Desarrollada con Flask y técnicas de procesamiento de lenguaje natural.

## 🚀 Características Principales

### 🔧 5 Herramientas Integradas

- **📝 Parafraseo IA** - Reescribe textos manteniendo el significado con diferentes estilos
- **✏️ Corrector Ortográfico** - Detecta y sugiere correcciones para errores comunes
- **💡 Asistente de Escritura** - Proporciona sugerencias para mejorar la calidad del texto
- **🤖 Detector de IA** - Analiza la probabilidad de que el texto sea generado por IA
- **📊 Analizador Detallado** - Evalúa originalidad y riesgo académico por párrafos

## 🛠️ Tecnologías Utilizadas

### Backend
- **Python 3.8+** - Lenguaje principal
- **Flask** - Framework web
- **NLTK** - Procesamiento de lenguaje natural
- **Scikit-learn** - Algoritmos de machine learning
- **NumPy** - Cálculos numéricos

### Frontend
- **HTML5** - Estructura semántica
- **CSS3** - Estilos y diseño responsive
- **JavaScript** - Interactividad del cliente
- **Font Awesome** - Iconografía
- **Google Fonts** - Tipografía Inter
